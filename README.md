# Nuvio Ultimate FR

Collection Nuvio en français avec des visuels animés cohérents.

## Catégories personnalisées
- Films récents
- Séries récentes
- Populaires
- Les mieux notés
- Films et séries français
- Marvel — Ordre chronologique

Les images sont générées dans `assets/`, et le fichier importable dans `Nuvio-Ultimate-FR.json`.

## Publication
Le dépôt doit être **public** pour que les URLs `raw.githubusercontent.com` soient accessibles à Nuvio.
Les ressources sont générées par GitHub Actions à partir de `scripts/generate_assets.py`.
